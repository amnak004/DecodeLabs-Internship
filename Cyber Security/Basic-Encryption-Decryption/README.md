# Basic Encryption & Decryption

## Description

A simple Python program that demonstrates basic encryption and decryption using the Caesar Cipher technique.

The program allows the user to enter text and choose a shift key. It then encrypts the text using the selected shift and decrypts it back to the original text.

## Features

- Encrypts user-provided text
- Decrypts encrypted text
- Allows the user to choose the shift key
- Preserves spaces and special characters
- Displays original, encrypted, and decrypted text

## Technologies Used

- Python
- String Handling
- Functions
- Conditional Statements
- Caesar Cipher
- Basic Encryption Concepts

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal inside the project folder.
4. Run:

`python encryption.py`

5. Enter the text you want to encrypt.
6. Enter a shift key.
7. The program will display the encrypted and decrypted text.

## Example

Input:

`Hello World`

Shift Key:

`3`

Output:

`Encrypted text: Khoor Zruog`

`Decrypted text: Hello World`

## Security Note

The Caesar Cipher is a basic educational encryption technique and is not suitable for protecting sensitive or real-world data. Modern applications use stronger cryptographic algorithms.
