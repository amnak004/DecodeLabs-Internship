# Password Strength Checker

## Description

A simple Python program that checks the strength of a password based on its length, uppercase letters, numbers, special characters, and common password usage.

## Features

* Checks password length
* Detects uppercase letters
* Detects numbers
* Detects special characters
* Identifies common passwords
* Classifies passwords as Weak, Medium, or Strong
* Provides suggestions to improve password strength

## Technologies Used

* Python
* String Handling
* Conditional Statements
* Basic Security Concepts

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal inside the project folder.
4. Run the following command:

```bash
python password_checker.py
```

5. Enter a password when prompted.
6. The program will display the password strength and suggestions.
